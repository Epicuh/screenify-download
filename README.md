# Screenify Android download

This repository hosts the public, tracking-free download page and signed Android
release assets for Screenify.

Version 1.0.20 pixel-aligns the Settings and main-screen wordmarks, centers the
connection-help close icon, and restores the signed update-check path. It retains
the pinned local TLS connection and low-latency native visualizer transport.

The APK binary is distributed through GitHub Releases rather than committed to
the repository.
